# Projecto-poo
La Microempresa elegida es una Barberia. 

Nombre de la Barbería: 

Kevin's Barbería 


Descripción del Negocio 

 

Kevin's Barberia  es una barbería urbana y moderna enfocada en brindar una experiencia de estilizado masculino de alta calidad. Se especializa en cortes de cabello de tendencia, degradados, diseño y arreglo de barba, y tratamientos capilares.
